# Java

1. Java是虚拟机，Javac是编译器，使用编译器将.java文件编译成字节码.class后使用java来让代码在JVM上运行
1. 一个Java源码只能定义一个public类，在运行时，将类名传递给java即可
1. 判断引用类型是否相等，如果使用==表示两者是否指向同一块内存，使用equals来判断二者值是否相等

## 类

1. 可变参数：type...表示可变参数，也就是任意多个type类型的参数，在内部通过数组方式访问可变参数
1. 子类构造函数的第一个语句一定是调用父类的构造函数，如果没有写会自动加上super()，所以如果父类没有默认构造函数的话就会出错
1. 向上转型：父类指针指向子类实例
1. isinstanceof: 用于判断某个指针指向的实例是否是某种特定类型，用于向下转型

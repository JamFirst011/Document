# 双曲函数

由 $e^x,e^{-x}$ 组成的函数称为双曲函数，有双曲正弦函数 $sh x = \frac{e^x-e^{-x}}{2}$
双曲余弦函数 $ch x = \frac{e^x+e^{-x}}{2}$
双曲正切函数 $th x = \frac{sh}{ch}$
可以通过这些函数导出一些恒等式

双曲函数的返函数为反双曲函数，和对数函数有关

1. 反双曲正弦函数：$arsh x = ln(x+\sqrt{x^2+1})$
1. 反双曲余弦函数：$arch x = \pm ln(x+\sqrt{x^2-1})$
1. 反双曲正切函数：$arth x = \frac{1}{2} ln \frac{1+x}{1-x}$

注意他们在积分中的特殊用处，即
1. $\int \frac{1}{\sqrt{x^2+a^2}}dx = ln(x+\sqrt{x^2+a^2})$
1. $\int \frac{1}{\sqrt{x^2-a^2}}dx = ln|x+\sqrt{x^2-a^2}|$
1. $\int \frac{1}{x^2-a^2}dx = \frac{1}{2a}ln|\frac{x-a}{x+a}|$

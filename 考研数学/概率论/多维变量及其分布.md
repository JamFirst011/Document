# n维随机变量及其分布函数

**定义**：如果有X1-n为定义在同一个样本空间上的随机变量，即为n维随机变量；n=2时为二维随机变量；

### 概念和性质

**分布函数**： $F(x_1,x_2,\cdots,x_n) = P\{ X_1 \le x_1, X_2 \le x_2 \cdots \}$ ,他具有如下性质：
1. 单调不减，对于x和y都单调不减
2. 右连续性，固定x和y，如果有跳跃间断点，那么只有左极限
3. 有界性： $F(-\infty,y) = F(x,-\infty) = F(-\infty,-\infty) = 0, F(\infty,\infty) = 1$
4. 非负性： $P\{x_1 < X \le x_2, y_1 < Y \le y_2\} = F(x_2,y_2) - F(x_1,y_2) - F(x_2,y_1) + F(x_1,y_1)$

### 边缘分布函数

边缘分布函数即x或y的分布函数，可以由n维随机变量分布函数推出，即 $F_X(x) = P\{X \le x\} = F(x,\infty)$

# 常见的两类二维随机变量

## 离散型随机变量

1. **概率分布和边缘分布**： 二维随机变量的取值对有限，则概率分布即为他们的分布率/联合分布率，形式和一维时形似，用表格表示，例如：

| | $y_1 \cdots y_j \cdots$ | $P\{X = x_i\}$ |
| ---- | ---- | ---- |
| x1 | $p_{11} \cdots p_{1j} \cdots$ | $p_{1\cdot}$ | 

只列出一行，下面的以此类推，表格的最右边一列和最下面一行分别为X和Y的边缘分布；由此可以得出X和Y的边缘分布函数；**注意**,联合分布函数可以近似成一个数列，数列和为1；

2. **条件分布**：如果X，Y符合分布 $p_{ij}$ ,对于固定的j，即固定的Y，则有条件分布： $P\{X=x_i | Y = y_j \} = \frac{P\{X=x_i,Y = y_j\}}{P\{Y = y_j\}} = \frac{p_{ij}}{p_{\cdot j}}$

**注意**：离散型随机变量没有概率密度，他的边缘分布实际上就表示了取某个值的概率(但是联合分布函数还是符合最开始分布函数的定义，即一个范围)；

## 连续性随机变量

**注意**：
1. 联合分布决定边缘分布和概率密度，但是反过来不一定成立，如果两个多维随机变量的联合分布相同，那么其他的大概率相同；但是如果边缘分布相同，但是一个是独立的，一个是相关的，那么求出来的联合分布就不相同；

1. **概率密度**：分布函数可以表示成 $F(x,y) = \int_{-\infty}^ydv\int_{-\infty}^x f(u,v)du$ ，那么f就称为概率密度；函数f是概率密度的充要条件是恒正，并且整个实数域的二重积分值为1；

2. **联合分布函数和概率密度**：即X和Y属于某个区域的P就是概率密度函数在这个区域上的二重积分;联合分布函数的混合偏导是概率密度
3. **边缘概率密度**: 即X/Y的概率密度函数，也是用分布函数来推导的，因为 $F_X(x) = F(x,\infty) = \int_{-\infty}^x\int_{-\infty}^{\infty} f(u,v)du$ ,因此里面那项就是X的边缘概率密度；实际上是概率密度函数中，取得一个x，对于x和任意y组成的点构成的区域内的二重积分的值; 若XY独立，并且给出了XY的边缘概率密度，那么他们的乘积就是XY的联合概率密度
4. **条件概率密度**：$f_{Y|X}(y|x) = \frac{f(x,y)}{f_X(x)}$ ，条件概率密度等于联合概率密度和边缘概率密度的商；用这个公式同样可以计算联合概率密度等；条件概率密度的对y的积分即为条件分布函数，即 $F(y|x) = \int^y_{-\infty} f(y|x)dy$

### 常见的二维分布

1. 二维均匀分布：在某个区域内有均匀分布，则概率密度函数为：$\frac{1}{S}$
2. 二维正态分布：概率密度及其复杂，看书69页；$\rho$ 表示两个随机变量的相似度，如果两个变量独立，则相似度为0(注意相似度为0无法推出两个变量独立), 联合概率密度公式为：

$$

    f(x,y) = \frac{1}{2\pi \sigma_1 \sigma_2 \sqrt{1-\rho^2}} exp(-\frac{1}{2(1-\rho^2)}[(\frac{x-\mu_1}{\sigma_1})^2 - 2\rho(\frac{x-\mu_1}{\sigma_1})(\frac{y-\mu_2}{\sigma_2}) + (\frac{y-\mu_2}{\sigma_2})^2])

$$

- 若 $(X_1,X_2) = N(\mu_1,\mu_2,\sigma_1^2,\sigma_2^2,\rho) -> X_1 = N(\mu_1,\sigma_1^2),X_2 = N(\mu_2,\sigma_2^2) $  ,也就是满足二维正态分布的两个随机变量分别满足一维正态分布
- 若两个随机变量独立，即相关系数为0，那么上面的结论反过来也成立

# 独立性

**概念**：如果对于二维随机变量的分布函数和边缘分布函数有 $F(x,y) = F_X(x) \cdot F_Y(y)$ ,那么随机变量X和Y相互独立，拓展都n维也是一样；

**充要条件**： 
1. n个随机变量相互独立：对于任意一组x，每个事件小于一个x的事件相互独立
2. 对于二维离散型随机变量，有： $P\{X=x_i,Y=y_j\} = P\{X=x_i\} \cdot P\{Y=y_j\}$ ,该定理拓展到n个离散型随机变量上也是一样；
3. 对于二维连续性随机变量，有： $f(x,y) = f_X(x) \cdot f_Y(y)$ ，拓展到n个上也是一样

### 性质

1. 对于二维离散型随机变量，条件分布等于边缘分布
2. 对于二维连续性随机变量，条件概率密度等于边缘概率密度

**如何证明X，Y不独立**：找到 $(x_0,y_0)$ ,使得不满足上述充要条件，也就是找到合适的x0y0，使得两个事件互相包含或者完全没有交集；此时二者独立

**总结**：独立用分布函数来定义，对于不同类型的随机变量有不同的充要条件/判断方法，对于离散型，用分布函数和边缘分布函数来判断；对于连续性，用联合概率密度和边缘概率密度来判断；

# 多维随机变量函数的分布

**概念**：X，Y为随机变量，那么Z=g(X,Y)也是随机变量；

**求法**：有三种可能：
1. XY都为离散型：这时候很简单，一一列出就可以了;**注意**：如果给出了XY两个离散型随机变量，要求(U,V)的概率分布，最好使用一一对照，即每一种(X,Y)情况都对应一种(U,V)情况，每个对应的UV情况的概率都为所有能形成这种情况的XY的概率和，具体看课后题3.11
2. XY其中一个是离散型，一个是连续性：将事件对离散型的一切可能值做全集分解，得到条件概率并分开讨论；例如，X1,X2为连续性，X3为离散型，求Z= X1+X3的分布，$F(z) = P(X3=1)P(X1+X3 \le z | X3=1) + \cdots$
3. XY都为连续性：$F(z) = P\{g(X,Y) \le z\} = \iint f(x,y)dxdy$ ，直接用二重积分很好求，即设定一个z，求出x和y满足这个z的区域，然后在这个区域上二重积分即可，但是注意，这种得到的是分布函数；也可以有如下的正规方法：

- XY为二维随机变量，有UV,U=u(x,y),v=v(x,y),求UV的分布函数：用他们的边缘概率密度来求，首先翻解出uv，即

$$
    x = x(u,v), y= y(u,v) \\
    f_{U,V}(u,v) = f(x(u,v),y(u,v)) \cdot |J| \quad |J|为雅可比行列式的绝对值
$$

得到UV的概率密度函数后，就可以用积分求UV的边缘概率密度和联合分布函数；如果要求Z=g(X,Y)的分布，也可以用上面方法，即u=g(x,y),v=y

- XY为二维随机变量，求Z=g(x,y)，反解出y，即y=h(x,z)，那么Z的边缘概率密度为 $f_Z(z) = \int f(x,h(x,z))|\frac{dh}{dz}|dx$, 这个方法实际上是对第一种方法的实践，**这里注意**积分的区域，求法为：**考虑函数Z=g(x,y),令Z为某一常量，可以得到一条曲线，该曲线对应的x的范围就是积分范围,例如x>0,y>0,Z=X+Y,那么当Z<1时,范围为0-z,当z大于1时范围为(z-1)-1**

## 特殊分布的求法

1. Z=max{X,Y}: F(z) = $P\{Z \le z\} = P\{X \le z , Y \le z \} = F(z,z)$
2. Z=min{X,Y}: $F_{min}(z) = P\{min(X,Y) \le z\} = P\{ X \le z \cup Y \le z\} = F_X(z) + F_Y(z) - F(z,z)$ ,当XY独立时，有 $F(z) = 1 - P\{min(X,Y) > z\} = 1 - P\{X > z\}P\{Y > z\} = 1 - (1-F_X(z))(1-F_Y(z))$ ,可以很方便的扩展到n个随机变量

3. 常见分布的可加性：如果相互独立的随机变量满足二项分布，泊松分布，正太分布，那么他们的和也满足这些分布即

$$

X -> B(n,p) , Y -> B(m,p) , X+Y -> B(n+m,p) \\
X -> P(\lambda_1), Y->P(\lambda_2) , X+Y -> P(\lambda_1+\lambda_2) \\
X -> N(\mu_1,\sigma_1^2) ,Y -> N(\mu_2,\sigma_2^2) , X+Y -> N(\mu_1+\mu_2,\sigma_1^2+\sigma_2^2)

$$

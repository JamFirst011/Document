# 计算机系统层次结构

**计算机系统的组成**：计算机由硬件和软件组成，软件包含程序数据和文档；某一功能即可以用硬件实现又可以用软件实现，则称为**软/硬件在逻辑功能上是等价的**；

## 硬件

**冯诺依曼**基本思想：存储程序的思想，控制流驱动方式，特点如下：
1. 计算机硬件由运算，控制，存储，输入/输出设备组成
2. 指令和数据以同样形式存储在存储器中
3. 指令由操作码和地址码组成

存储程序的基本思想：将实现编辑好的程序和原始数据送入主存储器后才能执行，一旦开始执行，不需要人员干扰，可以自动执行逐条指令

### 硬件部件

1. 输入设备
2. 输出设备
3. 存储器：分为主存和辅存(外存)，主存的工作方式是按存储单元地址进行存取；包含地址寄存器MAR，数据寄存器MDR，以及存储体；存储体中有很多存储单元，每个单元都有很多位；他的位长为存储字长，MAR的位数反应存储单元的个数；
4. 运算器：执行部件，核心是算数逻辑单元ALU，包含很多通用寄存器存储中间结果等；还有程序状态寄存器；
5. 控制器：由PC，指令寄存器IR和控制单元CU组成；将IR中存储指令的操作码送到CU，来生成微操作命令序列；运算器和控制器集成到一起就是CPU，CPU和主存构成主机，其他的都是外设；
6. 总线：包含数据/控制/地址线

## 计算机软件

按照功能可以分为
1. 系统软件：保证计算机系统正确运行的基础软件
2. 应用软件：用户为解决某哥应用领域中的问题而编制的程序

### 语言

1. 机器语言：二进制表示，是硬件能执行的唯一语言；
2. 汇编
3. 高级语言

进行语言转换的系统软件称为翻译程序，有如下翻译程序：
1. 汇编：将汇编转化为机器码
2. 解释：将高级语言逐条翻译成机器码并立即执行
3. 编译：将高级语言翻译成汇编或机器码

**软/硬件的逻辑功能等价性**：一个功能可以由硬件实现，也可以由软件实现

## 计算机系统的层次结构

从上到下分别为：

| 层次 | 功能 |
| ----- | ----- |
| 高级语言 | 面向用户，由高级语言编译器支持 |
| 汇编语言 | 汇编程序支持 |
| 操作系统层 | 操作系统程序实现 |
| 指令集体系结构ISA | 软件和硬件之间的界面；定义了硬件能执行的所有指令，软件可见的部分 |
| 传统机器语言层 | 微程序解释指令系统 |
| 微程序机器层 | 机器硬件执行微指令 |

## 计算机系统的工作原理

根据PC内容到主存中拿指令，存储到IR中，PC自增，取出操作码送入CU生成微程序，取出操作数并执行

**C程序的编译执行**：
1. 预处理，生成.i文件，文本表示
2. 编译，生成.s文件，文本表示
3. 汇编器，生成可重定位目标代码文件.o，二进制表示
4. 连接器，连接多个.o文件最终生成可执行文件

# 计算机的性能指标

## 主要性能指标

1. 机器字长：进行一次整数运算所能处理的二进制位数，由CPU决定
2. 存储字长：主存中一个存储单位的位数
2. 数据通路宽度：外部数据总线宽度，数据线可以并行传输的位数
3. 主存容量
4. 运算速度：
    - 吞吐量：单位时间内处理请求的数量
    - 响应时间：发送请求后系统响应请求所花的时间
    - CPU时钟周期：CPU工作最小的时钟单位
    - 主频：时钟周期的倒数
    - CPI：执行一条指令需要的时钟周期数
    - IPS：每秒平均执行的指令数量；
5. MIPS：每秒执行多少百万条指令
6. FLOPS：每秒执行多少次浮点数运算,还有M,G,T,P,E,Z,每个都多1000

几个专业术语：
1. 系列机：使用相同体系结构和指令系统的计算机系列
2. 兼容：相同的硬件和软件在多个计算机上都可以使用
3. 固件：将程序固化在ROM中，具有软件性质的硬件，吸收了硬件和软件的优点，操作系统一部分就是固件

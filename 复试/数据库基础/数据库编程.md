# 数据库编程

主要方式有嵌入式SQL，过程化SQL，存储过程和自定义函数，以及ODBC

# 嵌入式SQL

**主语言**：将SQL嵌入程序设计语言，例如C++中，这些称为主语言；一般采用预编译的方法处理，数据库管理系统首先扫描源码，将含有SQL语句的部分转化为函数调用后进行编译；以下全部用C语言为主语言，语法格式为 `EXEC SQL <SQL语句>`

## 嵌入式SQL和主语言之间的通信

有三种通信情况：
1. 向主语言传递SQL语句的执行状态，通过SQL通信区实现
2. 主语言给SQL语句提供参数，通过主变量实现
3. SQL语句将查询结果交给主语言处理，通过主变量和游标实现；

**SQL通信区**：包含了SQL语句执行后的，描述执行工作状态的信息；首先使用 `exec sql include sqlca` 定义通信区后，用其中的变量 `sqlcode` 来检查sql语句是否执行成功

**主变量**：分为输入/输出主变量，通过他们将数据输入SQL语句中，或从语句查询结果中带出数据；通过在 `exec sql begin declare section`中定义，在使用时，在变量名前面加:来进行区分；**指示变量**：主变量后面加：后再加一个变量称为指示变量，指示主变量的值或条件，例如如果主变量为null，那么指示变量就小于0，通过检测指示变量的值来判断主变量是否为null；

**游标**：SQL面向集合，而主变量面向记录，因此用游标，他为用户开设一个缓冲区存储查询结果，并可以使用游标逐条遍历结果；在声明游标时要为他指定一个查询语句，例如

``` sql
exec sql declare sx cursor for
    select sno,sname,ssex,sage
    from student
    where sdept = :deptname
exec sql open sx
```

在定义游标时不会执行查询语句，而在open游标后才开始执行；并使用如下方式遍历查询结果：

``` sql
for(;;){
    exec sql fetch sx into :hsno,:hsname,:hsex,:hsage;
}
```

将查询结果存储到后面的主变量中来进行进一步的处理；注意，如果要更新/删除数据，where子句中可以用游标指向的位置作为筛选条件，即 `where current of sx`

**不使用游标的SQL语句**,包括：
1. 查询结果为单个记录的select语句，此时直接 `exec sql select...` 进行查询，并在select语句后，from语句前加 `into...` 将结果存入主变量中即可；
2. 非current形式的增删改查语句；此时直接使用exec sql即可；

**使用游标的sql语句**：
1. 查询结果为多条的查询语句；
2. current形式的更新/删除语句；

**动态SQL**：即运行过程中才能确定要运行什么样的sql语句；通过动态组装sql语句和动态参数两种形式，过程如下：
1. **使用SQL语句主变量**：此时主变量中存储的是SQL语句的内容，在程序运行期间可以设定为不同的sql语句并执行，类型为字符串；在创建后，使用execute执行，例如 `exec sql execute immediate :stmt;`
2. 动态参数是SQL语句中的可变元素，用？表示参数所处的位置；在语句主变量声明后，用prepare来将动态参数和一个语句名绑定；例如 `exec sql prepare mystmt from :stmt`; 
3. 执行：使用execute，将上面的动态参数和**主变量**或**数据常量**绑定并运行，例如 `exec sql execute mystmt using 100;`

# 过程化SQL

过程化SQL的基本结构是快，所有程序都是由块组成的，快之间可以相互嵌套；通过过程化SQL，在SQL语句中加入了过程化的语句功能；快结构如下：

1. 定义部分：
    - declare
    - 变量，常量，游标等
2. 执行部分：
```sql
begin
    sql语句，过程化sql流程控制语句，例如while，for，if等
exception
    异常处理部分
end；
```

**变量定义**
1. 变量定义： `变量名 数据类型 [[not null] := 初值表达式]`
2. 常量定义： `常量名 数据类型 constant := 常量表达式`
3. 赋值语句：  `变量名 := 表达式`

## 流程控制：

**IF**: 
- `if condition then stmt end if;`
- `if condition then stmt else stmt end if;`
-  if语句嵌套

**循环语句**：
- `loop stmt end loop;`: 在stmt中用if语句和break等语句来结束循环
- `while condition loop stmt end loop;`
- `for count in [reverse] bound1... bound2 loop stmt end loop;`: 和python用法一致

# 存储过程和函数

这里说的快属于匿名快，不能被存储，每次被调用时都要进行编译；而过程和函数属于命名快，可以被存储到数据库中，并在其他过程中被调用；

## 存储过程

**优点**：
1. 在定义时进行编译，运行时效率更快
2. 客户直接通过调用进行数据库操作，减少了通信量
3. 可以将数据库操作方式写成函数，规范对一定数据库的操作

**具体存储过程如下**：
1. 创建：`create or replace procedure 过程名([参数1，参数2]) as <过程化SQL快>`
2. 执行：`call\perform procedure 过程名([参数...])`

**过程化SQL中游标**：可以使用带参数的游标，对查询结果进行访问，在声明游标时也声明参数，并在打开游标时传入参数，查询语句中可以使用这个参数，例如：
``` sql
cursor mycursor(leaderno char(3)) for
   select lname from leader where lno = leaderno;

open mycursor('l01');
```

# ODBC编程

如果需要同时操作不同的数据库管理系统，那么就需要不同的代码；使用ODBC可以用一种api连接和管理多个不同的数据源；

## 工作原理

**ODBC**应用系统的体系结构由上倒下分别为：
1. 用户应用程序
2. ODBC接口
3. ODBC驱动程序管理器: 对用户透明，检查ODBC的api调用的合法性，以及管理数据源的驱动；
4. 连接多个数据库驱动程序: 调用驱动程序支持的函数来存取数据库
5. 每个数据库驱动程序连接一个数据源: 为每个数据源设定一个数据源名，来抽象所有的底层软件；在使用时只需要对数据源名操作即可，而不需要知道具体的底层构造等；

## API以及工作流程

**句柄**：表示一个指针，分为：
1. 环境句柄：每个程序只有一个环境句柄
2. 连接句柄：建立多个连接句柄, 每个连接句柄可以连接一个数据源
3. 语句句柄：每个连接句柄可以连接多个语句句柄，以及多个描述符句柄(描述sql语句参数等)

**数据类型**：分为sql和c数据类型，通过如下方式进行转换：
- c到sql：通过SQLBindparameter来将应用程序变量传给语句参数
- sql到c：通过SQLBindcol来将查询结果绑定到应用程序变量；

**工作流程**：
1. 配置数据源
2. 初始化环境，声明句柄
3. 建立连接；
4. 分配语句句柄
5. 执行sql语句：
6. 处理结果集：注意游标自动生成而不需要声明

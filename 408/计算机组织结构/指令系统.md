# 指令系统

**指令集体系结构ISA**完整定义了软件和硬件的接口，指令系统是他的一部分，规定的内容主要包含：
1. 指令格式，寻址方式，操作类型
2. 操作数类型，大端/小端
3. 寄存器编号
4. 指令执行过程的控制方式

## 指令的基本格式

包括操作码OP字段，以及地址字段；指令字长为指令的长度，和机器字长没有固定的关系，如果指令字长为多个机器字长，那么需要多次访存才能读出一条指令；可以分为如下类型：
1. 零地址指令，可能包含对操作数的运算，此时操作数隐含的从栈顶弹出
2. 一地址指令：分为如下两种
    - 只有目的操作数，操作后存回原来的位置‘
    - 隐含的指定第二个操作数，运算结果放在ACC中
3. 二地址指令：
4. 三地址指令：专门用一个地址指出结果要保存到哪里
5. 四地址指令：在给出下一条要执行指令的地址

## 扩展操作码指令格式

使用变长的OP码，扩展指令类型；**扩展操作码**使得操作码的长度随地址长度而变化，不同地址数的指令拥有不同位数的操作码；例如，三地址码的OP码有4位，那么可以有15中三地址指令，剩下的那一种OP码作为二地址指令的OP码的前缀，以此类推，最终只有零地址码有16种；

**注意**：
1. 指令如果按照字节编址，那么指令字长必须是字节的整倍数

# 指令的寻址方式

寻址方式即确定指令和数据地址的方式，分为指令寻址和数据寻址

## 指令寻址

1. 顺序寻址：PC自动加一条指令的长度，形成下一条要执行指令的地址
2. 跳跃寻址：指令修改PC的值，由此来改变下一跳指令地址

## 数据寻址

在指令字中设置寻址特征字段，来表示使用的那种寻址方式；指令中的地址为形式地址，结合寻址方式可以得到真实地址；有如下寻址方式

1. **隐含寻址**：指令中只给出一个操作数地址，另外一个隐含，例如单地址指令的第二个指令隐含为ACC的值
2. **立即数寻址**：直接给出立即数作为操作数
3. **直接寻址**：直接给出地址，位数限制了寻址范围，操作数地址不易更改
4. **间接寻址**：形式地址给出主存位置，该位置存储操作数的地址，扩大了寻址范围，但是需要多次访存
5. **寄存器寻址**：给出寄存器编号，寄存器中存储操作数，很快，不需要访存，但是寄存器数量很有限
6. **寄存器间接寻址**：给出寄存器编号，寄存器中存放操作数真实地址；
7. **相对寻址**：PC加上形式地址为目标地址，用于指令跳转，注意，当读入指令后PC+1，随后在加形式地址；
8. **基址寻址**：基址寄存器加上形式地址为目标地址，基址寄存器可以默认也可以指定，面向操作系统；可以扩大寻址范围，不用考虑程序在主存中的具体位置
9. **变址寻址**：同样，变址寄存器内容加上形式地址变成目标地址，面向用户，一般是寄存器中的内容改变，作为偏移量，可以很方便的用变址寻址遍历数组；扩大寻址范围
10 **堆栈寻址**：分为硬堆栈和软堆栈：
    - 硬堆栈：寄存器实现，一般不适合
    - 软堆栈：主存中<br>
    这种寻址方式一般不给出形式地址，而是直接由栈指针指明目标数据的地址；

# 程序的机器级代码表示

## 常用汇编指令介绍

1. 寄存器：EBP存储FP，ESP存储SP
2. 汇编指令格式：一般有两种格式，ATNT和Intel，区别如下：
    - A只能用小写字母
    - A第一个为源操作数，第二个为目的操作数
    - A中寄存器和立即数需要加前缀
    - 都在指令码后面紧跟一个字符，表明操作数大小，例如byte,word,dword
3. 常用指令：主要分为数据传送指令，算数和逻辑运算指令，控制流指令
    - 数据传送：
        1. mov：两个操作数不能都是内存
        2. push：将操作数压入栈
        3. pop：先将内容出栈，在改变SP
    - 算术和逻辑运算指令：
        1. add/sub
        2. inc/dec: 自增/自减
        3. imul：有符号整数乘法，有2/3个操作数，将结果保存到第一个操作数的地址中，必须是寄存器
        4. idiv：整数除法，只有一个操作数表示除数，被除数位于特定寄存器中
        5. and/or/xor
        6. not:取反
        7. neg：取负数
        8. shl/shr：逻辑移位
    - 控制流指令：用于改变PC值，用label表示程序中的指令地址
        1. jmp
        2. jcondition：根据CPU的状态字进行条件跳转；
        3. cmp/test：相当于sub/and，但是他们不保存操作结果，只是产生状态字，来供条件跳转指令使用
        4. call/ret：call包含压入返回地址并跳转，ret则弹出返回地址并跳转

## 选择/循环语句的机器级表示

循环语句一般转换成do-while进行表示

## 过程调用的机器表示

调用者需要：
1. 压入参数
2. 保存现场
3. 压入返回地址随后跳转

被调用者需要：
1. 保存现场，为局部变量分配空间
2. 执行
3. 恢复现场，存储返回值，释放空间
4. 弹出返回地址，并跳转

其中有如下规定：
1. EA/C/DX为调用者保存寄存器，EBX,ESI,EDI是被调用者保存寄存器
2. 当调用者压入返回地址后，还需要将fp值压入栈，随后另fp=sp；在被调用者执行过程中，用fp访问参数
3. 在ret之前，将栈空间释放并恢复fp的值

# CISC和RISC的基本概念

指令系统的发展方向：
1. CISC：增强指令功能，设置更复杂的指令，实现软件功能的硬化
2. RISC：减少种类，简化功能，来提高指令的计算速度

## CISC

指令复杂庞大，指令长度不固定，各种指令使用频率相差很大，控制器采用微程序(因为太过复杂无法使用硬连线);

## RISC

指令长度固定，类型少，寻址方式种类少，只能用load/store访存，采用指令流水线使得多数指令在一个时钟周期内完成；硬布线控制为主

RISC显然性能更好，但是CISC有更好的兼容性，并且能提供更多功能，性能差距越来越小，因此CISC占多数

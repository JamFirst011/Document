# 常数项级数的概念和性质

1. **无穷级数**：$\sum_{n=1}^{\infty} u_n = u_1 + u_2 + \cdots$ ,其中 $u_n$ 称为通项
2. 若通项是常数，则称级数为常数项无穷级数
3. $S_n = u_1 + u_2 + \cdots + u_n$ 称为级数的部分和，若其存在，则级数收敛，若不存在或不定，则发散
4. 例如，等比级数，也就是等比数列，的敛散性判断如下：(设公比为q)
    - 若 $|q| < 1$ ,则级数收敛
    - 若 $q=1$ ,则S为无穷，级数发散
    - 若 $q = -1$ ,则S不定，级数发散
    - 若 $|q| > 1$ ,则S无穷，级数发散

## 性质

1. 收敛级数的线性组合也收敛
2. 改变级数任意项，不会改变他的敛散性
3. 收敛级数任意项加括号后仍然收敛
    - 若加括号后发散，则原级数发散
    - 若加括号后收敛，则无法判断原级数收敛
4. **若级数收敛，则通项趋近于无穷时等于0**,这是级数收敛的必要条件

# 级数敛散性的判别方法

### 正向级数的敛散性

1. 正向级数部分和一定大于0，所以只要看部分和是否有上界即可
2. 若任意部分和有界，那么级数收敛(见后面例题)
2. 比较判别法：给定两个正向级数，若小的发散大的也发散，常用下面的级数作为比较
    - 调和级数： $\sum_{n=1}^{\infty} \frac{1}{n}$
    - P级数: $\sum_{n=1}^{\infty} \frac{1}{n^p}$
    - 经典例题，很重要，16.15
3. 比较判别法的极限形式，和反常积分基本一样，就是比较趋于正无穷是级数项的比值
    - 若比值为0，那么分母级数收敛时分子级数收敛
    - 若比值为正无穷，那么分母级数发散时分子级数发散
    - 若比值为常数，那么二者有相同敛散性
    - 注意，这个方法对非正向级数有时候也可以使用
4. 比值判别法，令 $p = \lim \frac{u_{n+1}}{u_n}$
    - 若p>1,则发散
    - 若p<1,则收敛
    - 若p=1，那么无法判断
5. 根值判别法：若 $\lim u_n^{\frac{1}{n}} = p$ ,跟上面一样
6. 积分判别法：如果 $u_n$ 能表示成单调减少的非负连续函数f(x)，那么级数就和反常积分的值一样

### 交错级数的敛散性判别

1. **交错级数**：指一项正，一项负的级数
2. **莱布尼兹判别法**：如果每一项的绝对值单调不增，并且趋于0，那么交错级数收敛，注意这是充分条件不是必要条件

### 任意项级数及其敛散性判别

1. **绝对值级数**： $\sum |u_n|$ 为原级数的绝对值级数
2. 若绝对值级数收敛，那么原级数绝对收敛(证明方法很简单，因为原级数小于等于绝对值级数)
3. 若绝对值级数发散，但是原级数收敛，那么称原级数条件收敛
证明方法只要记住这个就好了：

$$
    v_n = \frac{1}{2}(|u_n| + u_n) , w_n = \frac{1}{2}(|u_n| - u_n)
$$

所以如果绝对值级数收敛，那么原级数收敛；如果绝对值级数发散，那么原级数的正项和负项组成的级数都发散

> 1. 两个绝对收敛的级数和也绝对收敛
> 2. 绝对收敛和条件收敛的和条件收敛
> 3. 条件收敛的无法判断
> 4. 若绝对值级数发散，不能判断原级数敛散性

**判断级数收敛的某些特殊情况**：
1. 若 $u_n^2$ 收敛，那么 $\frac{u_n}{n}$ 收敛
2. 若 $u_n$ 收敛，那么 $u_n^2$ 不一定
3. 若 $u_n$ 收敛，那么 $(-1)^n u_n$ 不一定
4. 若 $u_n$ 收敛，那么 $u_nu_{n+1}$ 不一定

# 幂级数和其收敛域

**函数项级数**：$\sum u_n(x)$ ，当x取定值时变成常数项级数

**幂级数**：若u为x的n次项，那么这个函数项级数称为幂级数，为 $\sum a_n(x-x_0)^n$ ，a称为幂级数的系数；任何一个有任意阶导的函数，都可以写成一个幂级数，其实就相当于泰勒展开；

**收敛点和发散点**：对于幂级数，如果在某点收敛，那么就是收敛点，某点发散就是发散点，所有收敛点就构成收敛域

**阿尔贝定理**：如何求解收敛域呢？如果在a点收敛，那么在 $|x|<a$ 内都**绝对收敛**；如果在b发散，那么在 $|x| > b$ 都发散，在端点处无法判断，只能带入，化成常数项级数后判断;注意，若原式为 $(x-x_0)^n$ ,x在a处收敛，那么 $x-x_0$ 就在 $|a-x_0|$ 处收敛，此时收敛域为 $|x-x_0| < |a-x_0|$

**收敛半径R**：在x的绝对值在小于R时收敛，大于R时发散;此处有一个重要结论，即若有 $\sum a_n(x-x_0)^n$ ,在x1处条件收敛，那么 $R = |x_1-x_0|$ 。因为幂级数在收敛区间内绝对收敛，在收敛区间外部发散

**收敛域的求法**：
1. 对于不缺项幂级数，求极限时`系数绝对值`的比值或根式，得到结果p，那么半径就是p的倒数,从而就得到了收敛区间和收敛域;注意收敛区间要验证两个端点
2. 若缺项，或者包含非幂级数(此时收敛域可能不对称，也没有收敛半径的说法)，那么令 $\lim \frac{|u_{n+1}(x)|}{|u_n(x)|} < 1$ ，即可解出x，即为收敛区间，并验证端点
3. 有时，上面的方法无法求出，即不存在极限，此时可以
    - 将系数项拆开，将原级数拆成两个级数的和，分别求收敛半径
    - 将原级数的偶数项和奇数项分别拆出来，构成两个级数，分别求收敛半径


注意，进行如下变换时收敛半径不变，但是收敛域可能变化：
1. 乘或除以 $(x-x_0)^k$
2. 求导,收敛域可能缩小
3. 积分,收敛域可能扩大

但是一般遇到这种抽象级数求收敛域，可以直接使用上面收敛域求法的第二个，这个是最根本的

**注意**：
1. 由多个级数和组成的级数的收敛域为各个级数的收敛域的交
2. 注意上述的收敛域求法都是充分方法，当收敛半径存在时，上述方法中的极限可能不存在

# 幂级数求和函数

### 概念

在收敛域上，即某个函数为幂级数的结果，则该函数为和函数；；

### 运算法则

若有两个幂级数 $\sum a_nx^n, \sum b_nx^n$ ,收敛半径分别为a，b，那么有

1. $k \sum a_nx^n = \sum ka_nx^n, |x| < a$
2. $\sum a_nx^n + \sum b_nx^n = \sum (a_n+b_n)x^n , r = min(a,b)$ ,若a=b，那么 $r \ge min(a,b)$
3. $\sum a_nx^n \cdot \sum b_nx^n = \sum_{n=0}^{\infty} (\sum_{i=0}^{n} a_ib_{n-i})x^n, R=min(a,b)$

### 恒等变形方式

1. 通项下标一起变，等于没变
2. 把一部分写出来，此时可以只变下标
3. 将一部分x提出来，这时候可以只变通项

后面求和函数有大用

### 性质

1. 幂级数的和函数在收敛域上一定连续
2. 和函数在收敛域上可积,收敛域可能扩大
3. 和函数在收敛域上可导,收敛域可能减小

### 重要展开式

1. $e^x = \sum \frac{x^n}{n!}, -\infty < x < \infty$
2. $\frac{1}{1-x} = \sum x^n , -1 < x < 1$
3. $ln(1+x) = \sum_{x=1}^{\infty} (-1)^{n-1}\frac{x^n}{n}, -1<x<=1$ , $\sum_{x=1}^{\infty} \frac{x^n}{n} = - ln(1-x)$
4. $sinx = \sum (-1)^n \frac{x^{2n+1}}{(2n+1)!}, -\infty < x < \infty$
5. $\frac{e^x-e^{-x}}{2} = \sum \frac{x^{2n+1}}{(2n+1)!}, x \in (-\infty,\infty)$
6. $arctanx = \sum (-1)^n \frac{x^{2n+1}}{2n+1}$

有大用，后面推到和函数时，其实就是将他们往这些上面转换;还有函数的幂级数展开式，直接求导过于麻烦，因此要用这些展开式推导

### 级数的和函数的求法

主要就是用上面的恒等变形，以及积分和导数，将他往重要展开式上面化，或者向等比数列上面化，如果过程中用了求导/积分，那么结果最后要变换回去；一定要记住求收敛域，可以用最初的形式求收敛域; 最终得到的收敛域，端点要带到级数中验证，并且和函数必须在端点处连续，才可以取

> 注意，如果要求某个常数级数的结果，但是看起来很难求时，尤其是分式结果的，可以将它转化为和函数，求出和函数后带入特定的值求解最终结果

# 函数展开成幂级数

就是泰勒展开，求法分为两种
1. 逐个计算导数，基本不用，太麻烦
2. 通过变量代换，四则运算，求导/积分化为上面的展开式后计算

**注意**：
1. 在对原式求导后，要积分回去时要用变上限积分，而不是直接不定积分(也可以不用，只是要带入特殊值求求导前原本可能含有的常数)
2. 最后判断收敛区间端点上是否成立时，不仅要看级数是否收敛，还要看原函数在该端点处是否单侧连续；

# 傅里叶级数

## 周期为2l的傅立叶级数

设f为周期为2l的周期函数，并且在[-l,l]上可积，那么如下为傅立叶系数：

$$
    a_n = \frac{1}{l}\int^l_{-l} f(x)cos\frac{n\pi}{l}xdx   \\
    b_n = \frac{1}{l}\int^l_{-l} f(x)sin\frac{n\pi}{l}xdx   \\
$$

如下为傅立叶级数

$$
    f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty} ( a_ncos\frac{n\pi}{l}x + b_nsin\frac{n\pi}{l}x )
$$

## 迪利克雷收敛定理

如果f为周期函数并且可积，并且满足连续或只有有限个第一类间断点，并且至多有有限个极值点，那么傅立叶级数处处收敛，并且他的和函数等于原函数在该点的左右极限的平均值，即 $\frac{左极限+右极限}{2}$

## 正弦级数和余弦级数

1. 若f为积函数，那么a恒等于0，所以他的展开式就是正弦级数
2. 若f为偶函数，那么b恒等于0，此时他的展开式为余弦级数

## 只在[0,l]上有定义的函数的正弦级数和余弦级数展开

若f的定义域为0-l，那么首先对其进行延拓，将其变为周期函数后求出傅立叶级数，并将定义域限定在0-l即可，大纲只要求奇函数延拓和偶函数延拓

# Java

1. Java是虚拟机，Javac是编译器，使用编译器将.java文件编译成字节码.class后使用java来让代码在JVM上运行
1. 一个Java源码只能定义一个public类，在运行时，将类名传递给java即可
1. 判断引用类型是否相等，如果使用==表示两者是否指向同一块内存，使用equals来判断二者值是否相等

## 类

1. 可变参数：type...表示可变参数，也就是任意多个type类型的参数，在内部通过数组方式访问可变参数
1. 子类构造函数的第一个语句一定是调用父类的构造函数，如果没有写会自动加上super()，所以如果父类没有默认构造函数的话就会出错
1. 向上转型：父类指针指向子类实例
1. isinstanceof: 用于判断某个指针指向的实例是否是某种特定类型，用于向下转型

***

1. 抽象类： abstract修饰类和方法，子类中使用override装饰该抽象方法
1. 使用高层抽象类引用，但是执行底层具体类定义的业务逻辑
1. 接口：如果一个类中没有字段，全都是抽象方法，那么就是接口。接口可以使用extends继承别的接口，类可以使用implements继承多个接口；可以使用抽象的接口引用来引用具体子类，并调用具体逻辑；接口中可以定义default方法，该方法有执行逻辑，子类不用一定要重载这个方法，用于为接口添加新方法时，如果添加default方法就不用在所有子类中都更新这个方法。接口中可以有字段，但是必须是static final修饰的，相当于定义属于这个接口模块的全局常量

#### 包和模块

1. 每个类都属于一个包，相当于namespace,在java文件开头使用package声明这个文件中的类属于哪个包，使用import导入别的包
1. 每个包都对应一个文件夹，其中存放在这个包中的java文件
1. 使用
``` java
    javac -d ./bin ./src/**/*.java
```
来将src下所有java文件编译并输出到bin目录中,使用
``` java
    java -cp bin main/Main
```
来执行main包中的Main.class文件
1. classpath: 即JVM在执行时查找类文件的路径，在运行时使用-cp命令设置，例如上面的运行命令，设置classpath为bin，并在bin中查找main/Main
1. jar包：将所有包目录打包到一个文件中，称为jar文件，相当于不带类之间依赖的类的容器，可以将jar包文件设置为classpath；也可以导入jar包中的包和类，直接import，并且在编译和执行时将jar包加到cp上即可
1. jar: 使用jar命令可以方便的生成jar包，并可以指定入口类，使得在执行 `java -jar pack.jar` 时会直接自动执行入口类
1. 模块：包含类之间依赖关系，就是在src文件夹中添加了module-info.java文件，其中定义模块名以及要导出哪些类，需要哪些模块

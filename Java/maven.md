# Maven

### 介绍

Maven提供了一套标准的项目结构和构建流程

### 依赖管理

每个jar包由如下三个字段确定：
- groupId
- artifactId
- version
可以在maven中央仓库中搜素jar包来得到上述信息，随后在pom.xml中添加这些信息即可，maven会在需要时下载这些jar包并缓存在本地。

### 构建流程

Maven有生命周期(lifecycle),阶段(stagee),目标(goal)的概念，有多个生命周期，每个生命周期负责不同的任务并由多个阶段组成，每个阶段由多个目标组成，目标实现具体业务；每次在mvn后面加的其实就是阶段名，就是从相应生命周期开始运行到指定阶段；每个goal都由插件完成，可以在配置文件中自定义插件(具体查),

### 模块管理

一般要将一个大型项目分为多个小模块，在一个maven项目中，可以手动创建多个maven项目作为模块，并在根目录下创建配置文件进行统一的编译。其中可以包含parent模块，类似抽象类，他的类型为pom不为jar，因为其中只有pom配置文件而没有源码，他代表了几个模块的相同配置；在创建这个模块的子模块时，可以声明这个parent模块，使得parent模块和当前模块拥有相同的配置.

# 创建型模式

## 建造者模式

用于创建大型复杂对象，其结构如下：
- Product
- builder
- ConcreteBuilder
- Director

其中，builder为抽象基类，用于定义创建Product需要的所有方法，而ConcreteBuilder则实现这些方法，Director中有builder成员，通过调用Builder成员的方法来来指挥对象的创建，和工厂方式不同的是，他是针对大型复杂对象而不是多个相似对象的创建的；

### Analyse

- **优点**：
    1. 客户不用知道产品内部组成细节，只要传入想要的ConcreteBuilder类型即可得到想要的Product
    2. 每一个具体建造者都独立
    3. 可以更加精细的控制Product生产的过程
    4. 添加新的建造者不用修改代码，符合OCP
- **缺点**：
    1. 无法创建不同且差异大的产品，因为创建过程都已经被写在Builder基类中
    2. 如果产品内部过于复杂，可能需要很多ConcreteBuilder，导致系统变得庞大
- **适用条件**：
    1. 需要生成的对象内部非常复杂
    2. 需要生成的产品对象的属性互相依赖，需要一定的赋值顺序

相比于工厂模式，建造者模式更注重一步一步，以很多不同独特的步骤来创建一个复杂对象；

## 原型模式

他的意义是，在系统中有很多十分复杂的对象，原型模式可以给出一个原型来指明所要创建的对象的类型，然后通过复制这个原型的方法来创建出更多这种复杂类型，并手动更改一些属性，来创建出很多复杂但是不同的对象，其组成如下：
- Prototype
- ConcretePrototype
- clien

客户用原型实例指定创建对象的种类，并通过调用他的clone方法得到一个完全一样的原型对象

### Analyse

- **优点**：
    1. 简化复杂对象的创建过程
    2. 提高对象创建的效率
- **缺点**：
    1. 违反了OCP，因为如果原型类中要添加成员时，要就修改clone方法
    2. 如果对象内部复杂并且需要深拷贝，那么clone方法实现会非常复杂
- **适用场景**：
    1. 创建新对象成本较大
    2. 需要保存对象的状态，而对象的状态变化很小，那么可以使用原型模式

    
# 单例模式

确保单例类只有一个实例，并通过全局访问点(静态方法)来获取这唯一一个实例，包含单例类和client，单例类的构造函数为私有，并且包含一个静态对象，其类型为自身；有静态方法getInstance来获取或创建实例(需要同步)

优点显然是可以节约资源，但是可能影响线程安全，并且更加难以调试；

具体代码实例如下：

```java
// 单例类
public class Logger {
    // 静态实例（懒汉式，延迟加载）
    private static Logger instance;

    // 私有构造函数，防止外部实例化
    private Logger() {
        // 防止通过反射创建实例
        if (instance != null) {
            throw new RuntimeException("Use getInstance() to get the singleton instance");
        }
    }

    // 提供全局访问点（线程安全）
    public static synchronized Logger getInstance() {
        if (instance == null) {
            instance = new Logger();
        }
        return instance;
    }

    // 日志记录方法
    public void log(String message) {
        System.out.println("Log: " + message);
    }
}

// 客户端代码
public class Client {
    public static void main(String[] args) {
        // 获取单例实例
        Logger logger1 = Logger.getInstance();
        Logger logger2 = Logger.getInstance();

        // 记录日志
        logger1.log("First message");
        // 输出: Log: First message
        logger2.log("Second message");
        // 输出: Log: Second message

        // 验证是否为同一实例
        System.out.println("logger1 == logger2: " + (logger1 == logger2));
        // 输出: logger1 == logger2: true
    }
}
```

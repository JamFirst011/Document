# 单例模式

确保单例类只有一个实例，并通过全局访问点(静态方法)来获取这唯一一个实例，包含单例类和client，单例类的构造函数为私有，并且包含一个静态对象，其类型为自身；有静态方法getInstance来获取或创建实例(需要同步)

优点显然是可以节约资源，但是可能影响线程安全，并且更加难以调试；

具体代码实例如下：

```java
// 单例类
public class Logger {
    // 静态实例（懒汉式，延迟加载）
    private static Logger instance;

    // 私有构造函数，防止外部实例化
    private Logger() {
        // 防止通过反射创建实例
        if (instance != null) {
            throw new RuntimeException("Use getInstance() to get the singleton instance");
        }
    }

    // 提供全局访问点（线程安全）
    public static synchronized Logger getInstance() {
        if (instance == null) {
            instance = new Logger();
        }
        return instance;
    }

    // 日志记录方法
    public void log(String message) {
        System.out.println("Log: " + message);
    }
}

// 客户端代码
public class Client {
    public static void main(String[] args) {
        // 获取单例实例
        Logger logger1 = Logger.getInstance();
        Logger logger2 = Logger.getInstance();

        // 记录日志
        logger1.log("First message");
        // 输出: Log: First message
        logger2.log("Second message");
        // 输出: Log: Second message

        // 验证是否为同一实例
        System.out.println("logger1 == logger2: " + (logger1 == logger2));
        // 输出: logger1 == logger2: true
    }
}
```

# 迭代器模式

通过分离集合的存储和遍历，使得对于不同的集合，client不需要知道集合内部的实现方式，而能够使用统一的方式对其进行遍历；包含
- 迭代器接口
- 具体迭代器
- 聚合接口
- 具体聚合
- client

其中迭代器接口定义了迭代器都要实现的行为，例如next,haveNext，而具体迭代器则根据其对应的具体聚合类型实现这些行为，注意，一般迭代器内部都会包含具体聚合的引用；聚合接口定义了具体聚合需要完成的操作，一般是getIteration返回一个迭代器，而不同的具体聚合则包含列表，以及实现不同的getIteration可能返回不同的，用this来初始化的迭代器；这样client在拿到一个具体聚合时，可以调用这个方法来得到专属迭代器并用迭代器遍历这个聚合

优点是封装遍历逻辑，统一接口，符合OCP，缺点是增加复杂性和性能开销

```java
// 迭代器接口
public interface Iterator<T> {
    boolean hasNext();
    T next();
}

// 聚合接口
public interface BookCollection {
    Iterator<Book> createIterator();
}

// 具体聚合类
public class BookShelf implements BookCollection {
    private List<Book> books;

    public BookShelf() {
        this.books = new ArrayList<>();
    }

    public void addBook(Book book) {
        books.add(book);
    }

    @Override
    public Iterator<Book> createIterator() {
        return new BookShelfIterator(this);
    }

    // 提供访问 books 的方法给迭代器
    public Book getBookAt(int index) {
        return books.get(index);
    }

    public int getSize() {
        return books.size();
    }
}

// 具体迭代器类
public class BookShelfIterator implements Iterator<Book> {
    private BookShelf bookShelf;
    private int index;

    public BookShelfIterator(BookShelf bookShelf) {
        this.bookShelf = bookShelf;
        this.index = 0;
    }

    @Override
    public boolean hasNext() {
        return index < bookShelf.getSize();
    }

    @Override
    public Book next() {
        if (hasNext()) {
            return bookShelf.getBookAt(index++);
        }
        return null;
    }
}

// 书籍类
public class Book {
    private String title;

    public Book(String title) {
        this.title = title;
    }

    public String getTitle() {
        return title;
    }
}

// 客户端代码
public class Client {
    public static void main(String[] args) {
        // 创建书架并添加书籍
        BookShelf bookShelf = new BookShelf();
        bookShelf.addBook(new Book("Design Patterns"));
        bookShelf.addBook(new Book("Java Programming"));
        bookShelf.addBook(new Book("Algorithms"));

        // 获取迭代器
        Iterator<Book> iterator = bookShelf.createIterator();

        // 遍历书籍
        while (iterator.hasNext()) {
            Book book = iterator.next();
            System.out.println("Book: " + book.getTitle());
        }
        // 输出:
        // Book: Design Patterns
        // Book: Java Programming
        // Book: Algorithms
    }
}

```

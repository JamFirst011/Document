# 随机变量及其分布函数的概念，性质和应用

**随机变量**；定义为 $X = X(\omega)$ ,他的值会随机而定，实际上就是每个样本点对应的一个变量；

### 分布函数的概念和性质

**分布函数**：有随机变量X，x为任意实数，那么 $F(x) = P(X <= x)$ 为随机变量X的分布函数，即X服从F(x)分布；他有如下特定：
1. 单调不减函数，并且在负无穷为0，正无穷为1；
2. 一定是右连续函数，也就是说，如果有跳跃间断点，也就意味着这个点是一个离散概率变量，那么他有左极限，例如，当x小于1时f为0，当x大于等于1时f为1，而不能是x小于等于1时f为0；**原因**：如果有右极限，意味着从左往右x变了一点，f就增长了很多，这不合理；而有左极限，表示少了一个点，f就减少了很多，合理；这里如果实在理解不了可以看书P32

**应用**：可以得到随机变量在某个区间的概率；**注意**：如果是连续随机变量，那么某个特定值的概率为0；即P(X=c)=0

# 常见的两类随机变量--离散型随机变量和连续性随机变量

离散型随机变量即只能取有限个或可列无限个值；他有用表格表示的**分布列/分布率/概率分布**如下：

| X | x1 | x2 | $\cdots$ |
| ---- | ---- | ---- | ---- |
| P | p1 | p2 | $\cdots$ |

且所有p的和为1，他的分布函数就像阶梯一样，有很多跳跃间断点

**连续性随机变量**：取值连续，首先有概率密度f(x),他必须符合
1. f(x) > 0
2. $\int_{-\infty}^{\infty} f(x)dx = 1$

实际上表示了取到每一个点的概率；而分部函数即为：$F(x) = \int_{-\infty}^x f(t)dt$ ,即概率密度中x之前图像围成的面积；如果有求随机变量在某个区间的概率，等于概率密度在这个区间的积分值；并有如下和离散型随机变量很不同的性质：

$$
    P\{a < X < b\} = P\{a \le X < b\} = P\{a < X \le b\} = P\{a \le X \le B\}
$$

# 常见的随机变量分布类型

## 离散型

1. **0-1分布(B(1,p))** : 二项分布的特殊形式，随机变量只能取0，1两个值
2. **二项分布 - B(n,p)**: $P\{X=k\} = C_n^k p^k(1-p)^{n-k}$
3. **泊松分布 - $P(\lambda)$**: $P\{X=k\} = \frac{\lambda^k}{k!}e^{-\lambda}$ ,当二项分布的n很大p很小时，可用该分布近似二项分布，$\lambda=pn$ ,一般在题目中，要根据给出的概率值算出 $\lambda$
4. **几何分布 G(p)**: $P\{X=k\} = (1-p)^{k-1}p$ ,相当于n重伯努利试验中，第k次是第一次发生的概率
5. **超几何分布 H(n,N,M)**: $P\{X=k\} = \frac{C_M^kC_{N-M}^{n-k}}{C_N^n}$ ,相当于从有M个不合格品的N个产品中抽取n个，其中有k个不合格品的概率

## 连续性

1. **均匀分布 U(a,b)**：在区间a-b内均匀分布，此时所有值的概率都相等，概率密度为一条横线，分布函数为一次线性函数ax+b;
2. **指数分布 $E(\lambda)$**: 当x大于0时，概率密度函数为 $\lambda e^{-\lambda x}$ ，否则为0；
3. **正态分布 $N(\mu,\sigma^2)$**: 概率密度为 $f(x) = \frac{1}{\sqrt{2\pi}\sigma}e^{-\frac{1}{2}(\frac{x-\mu}{\sigma})^2}$ ，该图像关于 $x = \mu$ 对称，如果均值为0，方差为1，就是标准正态分布，他的分布函数无法直接得出；一般在做题中，一般将普通正态分布化为标准正态分布，即对于每个x，都将 $\frac{x-\mu}{\sigma}$ 作为输入，相当于对概率密度图像做了平移，此时他的概率密度图像一定是偶函数，更好考虑；

# 一维随机变量函数的分布

如果X为随机变量，那么Y=g(X)也是随机变量，称为随机变量X的函数；如何求Y的分布呢，有如下情景：
1. X和Y都是离散型随机变量：很简单，不多说，直接一一对应就好
2. **都是连续性随机变量**：此时有两种方法：
    - 定义法： $F_Y(y) - P\{Y\le y\} = P\{g(X)\le y \} = \int_{g(X)\le y} f_X(x)dx$ 
    - 公式法：如果g是单调可导函数，并且可以求出反函数，那么可以直接用X的分布函数求出Y的分布函数，如下：

$$
    令 Y = g(X)  的反函数为 X = h(Y) \\
    F_Y(y) = P\{Y \le y\} = P\{g(X) \le y\}
$$

此时可以通过反函数h，求出X的区间，若g是单增的，那么 $ X \le h(Y)$ ,否则 $ X \ge h(Y)$ ,知道了区间(直接带入X的分布函数就可以得到Y的分布函数，然后求导就可以知道概率密度函数)，就可以用概率密度函数积分，得到他的值，即为Y的分布函数；**注意**：不论题目给什么，最后都用分布函数来计算，也就是首先将概率密度函数转化为分布函数；
